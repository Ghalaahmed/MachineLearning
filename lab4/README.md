# Data Quality Assessment & Preprocessing

## Overview

This project applies data preprocessing techniques on the Chocolate Sales dataset. The objective is to assess data quality, clean the dataset, and prepare it for analysis.

## Tasks

* Identified data quality issues (data types, missing values, duplicates)
* Converted Date to datetime and Amount to numeric
* Applied median imputation for missing values (demonstration)
* Detected and removed outliers using the IQR method
* Normalized data using Min-Max scaling and Z-score
* Checked correlation and decided not to apply PCA due to weak correlation

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
