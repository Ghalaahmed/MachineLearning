## SVM Classification Lab

In this lab, we applied the Support Vector Machine (SVM) algorithm to classify the Iris dataset. We started by loading and exploring the dataset, then used visualizations such as pair plots and KDE plots to better understand the relationships between the features and the species classes.

After that, we split the dataset into training and testing sets, trained an SVM model using `SVC`, and evaluated its performance using a confusion matrix and classification report. We also used `GridSearchCV` to tune the model parameters, including `C` and `gamma`, and selected the best model based on the search results.

The lab showed how SVM can be used for classification tasks and how parameter tuning can help improve or confirm the model’s performance.
